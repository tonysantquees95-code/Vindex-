# Vindex · Vetorial Tech

Otimizador de hardware e organizador de arquivos do ecossistema Vetorial Tech.

- `core/`: motor em Rust (diagnóstico, limpeza segura, organizador, regras e API JSON).
- `desktop/`: app Windows (Tauri) sobre o motor.
- `app/`: interface (React + Tailwind), usada no Windows e no Android.
- `android/`: ponte nativa do Android.
